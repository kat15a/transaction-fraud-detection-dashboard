Transaction Fraud Detection & Risk Analytics Dashboard

## 📊 Project Overview

This project focuses on analyzing transaction data to detect fraudulent activities and assess risk levels using an interactive Power BI dashboard. It provides key insights into fraud patterns, high-risk accounts, and transaction trends to support data-driven decision-making.


## 🛠️ Tech Stack

* **Power BI** – Data visualization & dashboard creation
* **SQL** – Data extraction and transformation
* **DAX (Data Analysis Expressions)** – Calculated measures & KPIs

## 📌 Key Features

* 📊 KPI Cards: Total Accounts, Avg Risk Score, Fraud Rate
* 🚨 Fraud vs Normal Distribution Analysis
* 📈 Fraud Trends Over Time
* 🌍 Transaction Distribution by Location (Map Visualization)
* 🔍 Interactive Filters (Fraud Status, Risk Level)
* 📋 High-Risk Accounts Summary Table


## 💡 Key Insights

* Majority of transactions (~83%) are flagged as fraudulent
* Fraud risk is concentrated among a small number of accounts
* High-risk accounts show significantly higher fraud scores
* Fraud activity shows a declining trend over time (Feb → Apr)
* Certain geographic locations indicate higher fraud concentration


## 🎯 Business Impact

This dashboard helps:

* Identify high-risk accounts quickly
* Monitor fraud trends and patterns
* Support proactive fraud detection strategies
* Enable better decision-making for financial risk management
